# 🛍️ Myntra Clone (Full-Stack E-commerce)

A full-stack e-commerce application inspired by **Myntra** with user authentication, product browsing, cart & wishlist management, and a secure checkout flow.

## 🚀 Live Demo

**Frontend:** https://myntra-clone-intership.vercel.app

---

## 🛠 Tech Stack

### Frontend
- React Native (Expo)
- Expo Router
- NativeWind (Tailwind CSS)

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

---

## ✨ Features

- User Authentication (Login & Signup)
- Product Listing
- Cart Management
- Wishlist
- Secure Checkout
- Responsive UI

---

## 📦 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Manas-2007/Internship-Training.git
cd Internship-Training
```

### 2. Install Dependencies

**Frontend**

```bash
cd Myntra
npm install
```

**Backend**

```bash
cd Backend
npm install
```

---

## ⚙️ Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=2000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

If required, create a `.env` file inside the **client** folder.

```env
EXPO_PUBLIC_API_URL=http://localhost:5000
```

---

## ▶️ Run the Project

### Start Backend

```bash
cd Backend
npm run dev
```

### Start Frontend

```bash
cd Myntra
npm start
```
